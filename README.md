# Order Analytics Clean V3

This version removes `vite.config.js` and `@vitejs/plugin-react` completely.

## Backend
cd backend
py -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
python app.py

## Frontend
Open a NEW terminal:
cd frontend
npm install
npm run dev

Supported: CSV, JSON, XLSX, XLS, XML.

Do not copy files from the old project into this version.
